# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in this repository, please report it responsibly.

**Do NOT open a public issue for security vulnerabilities.**

Instead, please email the maintainer directly or use GitHub's private vulnerability reporting feature.

## Scope

This is a curated list repository. Security concerns may include:

- Malicious tool links
- Phishing attempts
- Incorrect safety information

## Response

We aim to respond to security reports within 48 hours.
