# Contributing to Awesome AI Tools

Thank you for considering contributing!

## Adding a Tool

1. **Fork** the repository
2. Add your tool to the appropriate category
3. Follow the format: `| [Name](URL) | Description | License/Access |`
4. **Alphabetical order** within categories
5. Ensure the link works
6. Submit a **pull request**

## Quality Standards

Your tool should:

- Have a working website/repository
- Have meaningful documentation
- Be actively maintained (commit in last 6 months)
- Not be a duplicate of existing entries
- Provide clear value to the community

## Categories

- **APIs & Providers**: Commercial API services
- **Open-Source LLMs**: Models with open weights
- **Code Assistants**: IDE integrations and tools
- **Agents**: Autonomous AI systems
- **RAG & Vector DB**: Search and retrieval
- **Image/Video/Audio**: Creative AI
- **Local AI**: Self-hosted solutions
- **Frameworks**: Core libraries

## Style Guide

- Start with `[Tool Name](URL)`
- Keep descriptions under 100 characters
- Use title case for tool names
- No promotional language

## Pull Request Process

1. Update README.md only
2. One tool per PR (preferred)
3. Include a brief description of the tool
4. Wait for review (usually < 48 hours)
